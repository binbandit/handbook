# Playbooks

Playbooks are complete ways of working with AI. They begin with an outcome, connect the right context and tools, define escalation points, and end with observable evidence.

- [Context to completion](context-to-completion.md): the default loop from a clear finish line to a verified handoff.
- [Delegation without chaos](delegation.md): split independent work while keeping one accountable integrator.
- [Verification that earns trust](verification.md): match evidence to the ways a change can fail.
- [Git and GitHub as agent infrastructure](git-and-github.md): use clean state, checkpoints, review, and CI as shared memory for agents and people.

These are defaults, not rituals. Keep the loop lightweight for a small task and add structure only when it reduces real uncertainty.
