# Agent tools

The tools in this section exist to increase an agent's useful reach. Each one should reduce coordination cost, improve context, make state easier to inspect, or close a delivery loop.

| Tool | Status | Role in my system |
| --- | --- | --- |
| [Herdr](herdr.md) | Active use | Coordinates persistent terminal agents and exposes their state to people and agents |
| [Kite](kite.md) | Active use | Separates cheap working checkpoints from polished Git history and pull request context |
| [AXI](axi.md) | Awareness only | A design lens for making tool interfaces efficient and legible to agents |

An agent-facing tool must justify more than convenience. Its guide documents what context leaves the machine, which actions mutate state, how to verify it, and when the added trust boundary is not worth the benefit.
